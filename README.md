### 🌟 ویژگی‌های پروژه
* **جمع‌آوری خودکار:** دریافت لینک‌های پروکسی از منابع معتبر به صورت مداوم[cite: 1].
* **تست زنده و پینگ (Latency):** بررسی پایداری اتصال TCP و محاسبه دقیق سرعت پاسخ‌دهی هر پروکسی.
* **مرتب‌سازی هوشمند:** دسته‌بندی پروکسی‌ها بر اساس کمترین پینگ (سریع‌ترین‌ها در ابتدا).
* **ارسال به کانال تلگرام:** ارسال فایل سابسکرایب و ۳ پروکسی فوق‌سریع برتر همراه با دکمه‌های شیشه‌ای اتصال مستقیم.
* **پین خودکار:** سنجاق کردن پیام پروکسی‌های برتر در بالای کانال تلگرام.
* **اجرای خودکار:** به‌روزرسانی خودکار هر ۴ ساعت یک‌بار توسط GitHub Actions[cite: 1].
